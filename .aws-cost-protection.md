# AWS Cost Protection Guide

This app is configured to stay within AWS Free Tier limits and prevent unexpected costs.

## Free Tier Limits (First 12 Months)

### API Gateway
- **Free Tier**: 1 million API calls per month
- **Configured Limit**: 10,000 requests/month (hard limit)
- **Throttling**: 5 requests/second, burst of 10
- **Cost**: $0 (within free tier)

### Lambda
- **Free Tier**: 1 million requests/month, 400,000 GB-seconds
- **Configured**: 128MB memory, 10s timeout
- **Cost**: $0 (within free tier)

### S3
- **Free Tier**: 5GB storage, 20,000 GET requests, 2,000 PUT requests
- **Cost**: $0 (within free tier)

### CloudFront (Optional)
- **Free Tier**: 50GB data transfer out, 2 million HTTP/HTTPS requests
- **Cost**: $0 (within free tier)

## Cost Protection Measures

1. **API Gateway Throttling**
   - Rate limit: 5 requests/second
   - Burst limit: 10 requests
   - Monthly quota: 10,000 requests

2. **CloudWatch Alarms** (Recommended)
   Set up billing alerts:
   ```bash
   aws cloudwatch put-metric-alarm \
     --alarm-name exercise-timer-cost-alarm \
     --alarm-description "Alert if costs exceed $1" \
     --metric-name EstimatedCharges \
     --namespace AWS/Billing \
     --statistic Maximum \
     --period 86400 \
     --threshold 1 \
     --comparison-operator GreaterThanThreshold
   ```

3. **AWS Budgets** (Recommended)
   Create a $0 budget:
   ```bash
   aws budgets create-budget \
     --account-id YOUR_ACCOUNT_ID \
     --budget file://budget.json \
     --notifications-with-subscribers file://notifications.json
   ```

## Monitoring Costs

Check your costs:
```bash
# View current month costs
aws ce get-cost-and-usage \
  --time-period Start=2024-01-01,End=2024-01-31 \
  --granularity MONTHLY \
  --metrics BlendedCost
```

## Estimated Monthly Cost

**Within Free Tier**: $0.00
**After Free Tier** (if limits exceeded):
- API Gateway: ~$3.50 per million requests
- Lambda: ~$0.20 per million requests
- S3: ~$0.023 per GB storage

With configured throttling (10K requests/month), even after free tier:
- **Estimated cost**: < $0.10/month

## Important Notes

1. **API Gateway throttling is enforced** - requests beyond limits will return 429 errors
2. **S3 bucket is versioned** - old versions auto-delete after 7 days
3. **Lambda timeout is 10 seconds** - prevents long-running functions
4. **No domain required** - uses AWS-provided URLs

## Disable/Delete Resources

To avoid any charges, delete the stack:
```bash
sam delete --stack-name exercise-timer-dev
aws s3 rb s3://exercise-timer-frontend-dev --force
```
